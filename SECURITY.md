# Security

The editor is a small web server on your own computer. It listens on 127.0.0.1 only, refuses writes that come from other websites, serves only the project's editor, preview and print folders, and opens only the desktop apps on its allowlist.

If you find a way around any of that, please report it privately with [a security advisory](https://github.com/murathany7/hardware-knowledge-hub/security/advisories/new) instead of a public issue. Include the steps to reproduce it. Fixes go into the next release; only the latest release is supported.
