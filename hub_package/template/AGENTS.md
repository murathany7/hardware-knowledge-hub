# Hardware Knowledge Hub project

Read [hardware/CLAUDE.md](hardware/CLAUDE.md) before proposing hardware changes. It records the components, measurements, wiring, design decisions, and open questions for this build.

Keep measured values and estimates distinct. When a hardware fact changes, update it in the editor or in `hardware/knowledge/knowledge.json`, then run `python3 hardware/knowledge/kb.py build` to regenerate the project notes.
